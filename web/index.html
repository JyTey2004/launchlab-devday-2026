GOOD TO KNOW

Before you begin.

Can my agent run the workflow today?+

Yes, in the local prototype. An MCP-capable agent can import a compatible project, create a versioned static preview, open a test mission and retrieve feedback. This website prepares a brief; it does not start a run. Rewards use demo credits with no cash value.

Does LaunchLab host any Web3 application?+

The current adapter supports static projects with a LaunchLab manifest. Backend execution, smart-contract deployment, wallet-enabled previews and managed public hosting are future capabilities. The included example is ready to try.

How will I use LaunchLab through OKX AI?+

OKX’s current service pages guide you to copy a service prompt into your own agent. We’re preparing that handoff for LaunchLab. You can draft your brief now; a verified listing and service ID will be added when the integration is ready. Read the official setup guide ↗

Where do the testers and rewards come from?+

For the first pilot, builders invite their own cohort. LaunchLab records the task, participation and evidence. Recruitment from an external tester network and real onchain payouts are not connected yet. Honest reports of failure should qualify just as useful successful attempts do.

Does a successful test validate demand?+

A test can reveal usability problems and whether someone can complete a task. Paid participation alone does not prove organic demand or willingness to buy. Keep those questions separate when interpreting the results.
