Use Node 22.12 or newer. No API key, wallet or environment file needed.

cd launchlab-devday-pulse
git checkout 76fa3ae06b8ea8a6a7fd1e58fa82723687296c72
npm ci --ignore-scripts
npm test
npm run dev
