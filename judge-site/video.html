The next era of founders

A new era of founders is here. Building a first version is easier than ever. But after the code comes a harder question. Will anybody use it? LaunchLab turns a repository into a measurable product experiment, so a founder can learn from a working product instead of another prediction.

Start with a repo and a question

Our example is Proof Reps, a crypto-themed gymwear store. Its source is a public GitHub repository. LaunchLab detects the Vite framework and pins the exact source commit. The founder defines the audience and the question: will gym-goers explore products, add an item to their bag, and complete a simulated checkout?

Approve the measurement plan

A GPT-driven agent proposes bounded code changes, event hooks, and feedback questions. The founder reviews the plan before it runs. The approved changes are applied to an isolated build copy. LaunchLab does not silently rewrite the original repository. The experiment keeps a record of the version and measurement plan.

A real deployed storefront

The approved application is built in AWS CodeBuild and hosted on Amplify. This is a real capture of the deployed store. Visitors can browse the collection, choose a size, add an item, and try the demo checkout. The checkout is simulated. No money moves, and no real order is placed.

Ask users what the clicks cannot tell you

In the instrumented deployment, visitors choose whether to share usage activity. They can then submit feedback about the experience. This capture shows an internal quality check of the feedback form. It verifies delivery and persistence. It is deliberately labelled as internal testing, and is not presented as a real customer's opinion.

Count actions separately from sessions

LaunchLab separates repeat actions from sessions and labels traffic cohorts. The current test snapshot records two browser sessions, two checkout actions, and one saved feedback response. Earlier repeated actions were not captured, and that limitation is disclosed. These numbers prove that the collection path works. They do not prove customer demand.

Results your agent can retrieve

The hosted service exposes nine authenticated tools over H T T P and M C P. A founder's agent can retrieve deployment details, status, activity, and feedback tied to the experiment. The dashboard provides the detailed view. The public judge walkthrough includes an interactive store copy and a redacted, read-only results snapshot, without private credentials.
