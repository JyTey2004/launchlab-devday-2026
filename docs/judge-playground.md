# Try LaunchLab as a founder

Start with the free browser example. The actual OKX service purchase is a separate, optional journey.

## 1. Try the finished product

[Open the browser playground](https://jytey2004.github.io/launchlab-devday-2026/try/).

1. In **Dev Day Pulse**, choose an agent job and audience, then create an experiment brief.
2. Try copying the brief or requesting a download. Share candid feedback; activity recording is optional.
3. Inspect the browser's local observations to see what your own test recorded.

This example needs no wallet, API key or service purchase. Briefs come from fixed templates. Observations stay in this browser; they are not a shared report from attendees, a LaunchLab deployment receipt or evidence of customer demand. A price preference is an opinion, and a download request does not confirm that a file was saved. Reloading can start another anonymous session; session counts do not identify unique people.

## 2. Optionally request the real service

Open the [Dev Day Pulse repository](https://github.com/JyTey2004/launchlab-devday-pulse) in a coding agent with the official **OKX AI skill** installed. Sign-in and supported network access are separate prerequisites. [Official connection guide](https://web3.okx.com/onchainos/dev-docs/okxai/agent-installation-guide). Paste:

```text
I've built Dev Day Pulse: https://github.com/JyTey2004/launchlab-devday-pulse

I want to find out whether first-time OKX Dev Day attendees can create a useful experiment brief without help, and what should improve.

Use the official OKX AI buyer workflow to find LaunchLab, Agent 13905, and its Launch and Validation Pilot. Show me the current offer and costs, then ask before purchasing.

Handle the setup for me: a test preview, optional usage tracking, feedback from people I invite, and a clear results report. Keep my original code unchanged and share the private task dashboard when available. Ask simple Yes/No questions for the plan and any extra costs.

If anything is blocked, explain what I need to do next. Use real observations; don't call rehearsal activity customer traction.
```

The agent must discover the current offer before purchase. This page does not establish a live fee, availability or buyer eligibility. Service purchase does not approve model spending, builds, hosting, deployment or final settlement. Provider readiness or provider model-funding blocks need the LaunchLab operator, not judge credentials. If the service is unavailable, stop at that checkpoint and explain it; the browser example remains a separate product demonstration.
